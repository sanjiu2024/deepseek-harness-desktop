# REQ-001 桌面客户端

状态：**已确认，实现中** · 2026-11-15 · 负责人 sanjiu2024

## 要做什么

用 Tauri 2 做一个跨平台桌面客户端，内核直接使用 DeepSeek Harness（`dsh --profile sdk`），
界面用 React 19 + shadcn/ui + Tailwind 4 从零重写。

对话能力必须完整：发送消息、流式接收回复、渲染工具调用与结果、处理审批与用户提问、
切换模型、浏览历史会话、管理多个会话。

## 不做什么

| 不做 | 原因 |
| --- | --- |
| 复用官方 Web 前端（`apps/web`, `packages/client`） | 需求是重写 UI，不是换壳 |
| 复刻 Typert Remote 协议（34 个 namespace） | 成本高于本项目其余全部工作之和 |
| 修改 dsh 源码 | 内核按版本拉取，保持可升级 |
| 内置插件市场 / MCP 管理 | 第一版不做，内核仍支持 |
| 移动端、Web 版 | 只做桌面 |
| 多内核版本共存 | 钉一个版本，升级走一行 diff |

## 已知边界（来自上游的限制，不是我们的待办）

1. **历史会话要自己读盘**：SDK 无「列出会话」方法，`session/resume` 也不重放历史事件。
2. **换模型 = 换进程**：`initialize` 把 provider/model 钉死在 runtime 实例上。
3. **体积下限约 150 MB**：内核跑在 Node 上，运行时省不掉。

## 验收标准

每条都必须能跑出结果，不能写给「应该可以」。

- [ ] `pnpm install && pnpm kernel:fetch && pnpm tauri dev` 在干净环境启动到主界面

- [ ] `pnpm --filter @dsh-desktop/app check` 无错误

### 体积决策

原计划安装包 150~250 MB。实测内核未剪枝 **819 MB**（`du -sh kernel`），
其中 LibreOffice 工具链占 337 MB、Web 前端与 UI 包占 45 MB —— 这些 `sdk` profile 一行都不用。
体积目标改为「M6 剪枝后实测」，不再给未验证的数字。
